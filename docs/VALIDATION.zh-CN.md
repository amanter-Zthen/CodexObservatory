# 0.4.9-r3 公开版本验证

[English](VALIDATION.en.md) · [首页](../README.md)

本次 r3 修复子代理生命周期；本机定点结果与公开源码重建分开记录。下方 r2、r1 和更早结果保留为历史验证，不计作 r3 重跑。

## r3 子代理生命周期验证 · 2026-11-13

- 旧版负对照复现继承元数据覆盖会话身份，以及已完成子代理行残留。
- 本机修复版 Go 后端与 floatui 套件通过 172 个顶层检查、231 个含子检查，覆盖嵌套继承、父子隔离、后续轮次、取消、迟到响应、工具等待和旧缓存迁移。
- 只读回放 18 份真实子代理日志，完成后残留为 0；正式接口复核中两条已完成残留均已消失。公开仓库不包含这些日志或路径清单。
- 47 项视觉运行文件核对一致。六层视觉、流光和速度算法、显示 EXE、采集 watcher 与网络协议未改，也没有新增持续轮询或历史。
- 固定参考 [codex-statusbar 提交 `17f0ddd`](https://github.com/dongyue-19/codex-statusbar/tree/17f0ddd25512b9a823b56a37da325d36ca53971f) 对同两条会话的探针分别为 idle / completed，未复现持续运行；结论限于该提交和这两条会话。
- 公开源码重建通过 171 个顶层检查、230 个含子检查；真实日志回放默认跳过。另有 4 个采集器信任包定点检查通过，`native/` 原件不变。可选回放见 [构建说明](BUILD.zh-CN.md)。

## r2 定点验证 · 2026-10-31

- 采集器信任包：4 个顶层检查通过，包含 Windows EKU 的 4 个子项；重复初始化、原身份保留和失败写入的恢复边界均覆盖。
- 混合速度：11 项通过，原文字数字插值对照误差为 0；行切换保留有界内存。
- 日常 token 流光：14 项通过，实际 WebGL 中模型名与数字均发生光效像素变化，新增纹理为 0，GL 错误与页面错误为 0。
- 公开构建入口：原显示覆盖层 26 个顶层、77 个含子项检查通过，另执行上述 4 个采集器检查；保留原生源文件不变。
- 独立 Windows/Python ROOT 对照得到相同的 57 张公共 TLS 根，与此前实际恢复连接的公共根集合一致。此数量属于验证机器，不是硬编码常量。
- r2 验证时，新 watcher 需待下一次正常启动才加载；文件落盘与运行激活分别记录。公共发布不包含作者机器的证书、身份、配置或原始日志。

以下 r1 记录为保留的历史验证；r2 发布时未重跑整套长压力、跨进程鼠标或视频渲染。
