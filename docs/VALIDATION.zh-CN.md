# 0.4.9-r1 公开版本验证

[English](VALIDATION.en.md) · [首页](../README.md)

本次修订在 Windows 开发机器的独立公开源码目录中，重新构建 C++ 显示宿主，验证输入窗口修复和改动后的视觉链路。Go 后端与 native 构建继续使用同一输入和产物；下方单独列出保留的先前验证，不把它们计成本轮重跑。发布工作没有重启运行中的生产程序，也没有改动其网络、后端或 watcher。

## r1 重新验证

| 检查 | 结果 |
| --- | --- |
| C++ 宿主 | 新公开构建入口真实编译 PASS；MSVC x64、WebView2 SDK 1.0.2903.40、AMD64 GUI 子系统 |
| 输入几何 CPU 检查 | 12 项检查、60 组几何用例 PASS |
| 外缘与圆角穿透 | 216 DPI、100% / 125% 缩放下，真实跨进程左键、右键、滚轮与圆角检查 PASS |
| 面板内交互 | 拖动、菜单、隐藏重开 PASS |
| 原生宿主生命周期与回退 | 6 组套件 PASS |
| 基础视觉 | 7 组脚本重跑 PASS，覆盖布局、编排、玻璃、时序、身份文字、曲线层级和六层独显 |
| 当前视觉 | 15 项重跑 PASS，覆盖镜头、文字流光、预热、单待绘帧和背压 |
| 工程约束 | 21 项重跑 PASS，覆盖消息时序、过期状态、长文字图集、有界绘制和回退 |
| 桌面页面控制 | 18 项重跑 PASS，覆盖透明、缩放、隐藏/恢复、重播、滚动、画质及渲染余量 |
| 组装页面玻璃状态 | 新增 9 项检查 PASS，覆盖真实数据驱动链与玻璃联动 |
| 压力运行 | 120 秒 PASS；601 次状态输入，最大一个待绘帧和一个 fence，播放长任务为零 |
| 构建脚本契约 | 17 项合成检查重跑 PASS；假编译器验证脚本边界，不代替真实编译 |
| 演示 | 3840 × 2160 @ 60 fps、37 秒、2220 帧，最终 hidden；H.264 视频与 AAC 音轨完整解码 PASS |

r1 的输入实现将大视觉 HWND 设为纯穿透，独立小圆角输入 HWND 只覆盖面板。外缘点击穿透已由下方独立进程实际收到输入确认，不再仅以隐藏窗口或几何计算代替桌面交互验收。

演示通过实际组装页面的 `SnapshotFeed → app.step → Animator → 六层` 链路生成，离线玻璃逐帧更新，覆盖空闲、一绿、含黄的两行、含红与 `gpt-6-astra` 的四行、新回合全绿、收拢和消散。状态联动针对玻璃片标记、墨色和对应档案，保留主体暖色材质。
