# 版本记录

[English](CHANGELOG.en.md)

## 0.4.9-r3 · 2026-11-13

- 修复子代理日志归属：保留文件首次建立的会话身份，继承的父会话元数据不再覆盖它，使文件完成事件与网络响应归属到同一子代理。
- 启动时核对旧缓存与源日志首条身份及事件归属；仅将错归属缓存按现有 4 MiB 增量块和扫描预算重新解析。
- 保持单次 response 完成不等同于 turn 完成，以及工具等待、后续轮次和迟到帧的现有语义；不新增持续轮询或历史。
- 修复通过 Go overlay 构建，冻结的 `native/` 原件不变；六层视觉、流光和速度算法、显示 EXE、采集 watcher 与网络协议保持原样。

发行标识为 0.4.9-r3，六层工程仍为 0.4.9，显示宿主为 shell.1，原生源码与兼容 API 基线仍为 0.4.8-nacre。本机定点结果与公开重建范围见 [验证记录](VALIDATION.zh-CN.md)；演示视频继续引用 r1 的视觉基线。

## 0.4.9-r2 · 2026-10-31

- 修复采集器初始化的 TLS 信任包：原 observer CA 与 Windows 公共 TLS 根共同保留，避免下一次初始化使公共服务证书验证再次失败。
- 同步混合速度显示：可见文字输出时保留原来的大数值估速；空档使用当前轮次最近的有效 token 速度。运行中有不超过约 ±11% 的装饰性变化，工具等待保持读数；两者通过原 0.65 秒插值衔接。
- 日常 token 输出按 20 / 50 / 90 tok/s 分四档驱动模型名、数字和 /s 的现有流光，强度为完整写字光效的 .22 / .34 / .48 / .62。分档由采样基线决定，装饰性波动不改变档位。
- 保持六层视觉、当前状态内存、原写字完整光效与静态模式。无新增 GPU 纹理、渲染通道、采样器或会话历史。
- 补齐中英文信任包、版本说明及构建/接入/接口说明。演示视频继续引用 r1 的六层基线，没有把旧视频标成 r2 实录。

发行标识为 0.4.9-r2，六层工程仍为 0.4.9；原生来源与兼容 API 标识保留 0.4.8-nacre。这些标识分别描述发行、视觉工程和接口基线，实际二进制以构建/包清单 SHA-256 为准。参见根目录 VERSION.json。

现有进程不因文件更新自动重载。Windows 启动器文件已经更新但旧 watcher 仍运行时，应标记为等待正常 watcher 启动，不能宣称新逻辑已激活。
